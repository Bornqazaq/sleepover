# Разработка «Комнаты»

Unity-проект находится в `igruha/`, а не в корне репозитория.

В начале работы прочитай `CLAUDE.md` и `igruha/CLAUDE.md`: это общие правила
команды для любого агента, включая замороженные настройки персонажей,
камеры и анимаций. Текущий статус и результаты проверок — в `STATE.md`;
задачи — в Linear, команда IGRUHA. Инструкция подключения — `TEAMMATE_SETUP.md`.

Работай в отдельной ветке задачи. Перед обновлением Git закрой Unity.
До первого запуска, включая batchmode, проверь наличие Synty по
`docs/art/synty-library.json`. После правок C# проверь компиляцию и Console;
сетевую логику проверяй Host + Client.

Инструкции фаз мини-игры находятся в `.claude/skills/`; читай соответствующий
`SKILL.md`, когда выполняешь эту фазу. Команды интерфейса Claude и названия
его моделей в этих файлах относятся к Claude Code.

Настройки MCP и пути конкретной машины хранятся в пользовательских конфигах.
Используй Unity MCP для работы с редактором и Blender MCP для работы с Blender.
Если Linear недоступен, сообщи об этом; не выдавай локальный журнал за
проверенный статус тикетов. Результаты сессии обновляй в `STATE.md`.
