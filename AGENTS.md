# Разработка «Комнаты»

Unity-проект находится в `igruha/`, а не в корне репозитория.

В начале работы прочитай `CLAUDE.md` и `igruha/CLAUDE.md`: это общие правила
команды для любого агента, включая замороженные настройки персонажей,
камеры и анимаций. Текущий статус и результаты проверок — в `STATE.md`
(он короткий, читается целиком; история прошлых проходов — в `docs/history/`,
навигация через `docs/history/README.md`, целиком её читать не надо);
задачи — в Linear, команда IGRUHA. Инструкция подключения — `TEAMMATE_SETUP.md`.

## Создание тикетов в Linear

- Перед созданием и обновлением тикетов прочитай `docs/templates/TICKET_TEMPLATE.md`
  и сверь эпик/спеку с `igruha/LINEAR_ROADMAP.md`.
- Все задачи игры «Комната» создавай в команде **IGRUHA** и обязательно
  привязывай к проекту **«Комната (Party-game)»** (`P-IGR-1`). Не оставляй
  поле проекта пустым: задачи без проекта не видны на проектной доске.
- Соблюдай формат заголовка и обязательные лейблы из шаблона: один `phase:*`,
  один лейбл области и тип по смыслу (`Bug`, `Improvement` или `Feature`). Для
  багов плейтеста используй `phase:playtest` и стандартный `Bug`; не создавай
  и не используй русскоязычный лейбл `Баги плейтеста`.
- Назначай тикет только указанному владельцу. Не меняй существующие статусы,
  описания, исполнителей и лейблы при добавлении новых меток.
- После записи перечитай тикеты с фильтром по проекту и проверь проект,
  команду, ответственного, статус и лейблы. В ответе перечисли номера и ссылки.

Работай в отдельной ветке задачи. Перед обновлением Git закрой Unity.
До первого запуска, включая batchmode, проверь наличие Synty по
`docs/art/synty-library.json`. После правок C# проверь компиляцию и Console;
сетевую логику проверяй Host + Client.

Инструкции фаз мини-игры находятся в `.claude/skills/`; читай соответствующий
`SKILL.md`, когда выполняешь эту фазу. Команды интерфейса Claude и названия
его моделей в этих файлах относятся к Claude Code.

Настройки MCP и пути конкретной машины хранятся в пользовательских конфигах.
Используй Unity MCP для работы с редактором и Blender MCP для работы с Blender.
Если Linear недоступен, сообщи об этом; не выдавай локальный журнал за
проверенный статус тикетов. Результаты сессии обновляй в `STATE.md`, держа его
коротким: прошлый проход переноси в `docs/history/STATE-archive.md` и пересобирай
указатель `python3 tools/state_index.py`.
