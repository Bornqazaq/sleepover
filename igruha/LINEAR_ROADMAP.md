# Linear Roadmap — Party-game «Комната» (MVP, 1 месяц)

> Как использовать: каждый **EPIC** = проект или label в Linear. Каждый **тикет** = одна issue. Тикеты намеренно мелкие (0.5–1 день) — бери сверху вниз внутри эпика. Порядок эпиков = порядок работы: не прыгай вперёд, пока не закрыт фундамент.

---

## ⚠️ Важные вводные (прочитать до старта)

1. **Физика — простой контроллер, НЕ active ragdoll.** GDD (разделы 6.3/6.5) фиксирует активный ragdoll — это **устаревшее** решение. По итогам обсуждения выбран простой Rigidbody-контроллер + смешные анимации (стиль Mecha Chameleon) + impulse-толчки для контакта. GDD нужно обновить, чтобы напарник не читал старое.
2. **Сетевой стек:** Unity Netcode for GameObjects (NGO) + Relay + Lobby. Host-based модель (один игрок хостит). Подтвердить с напарником-«Гением»; если заменит транспорт — меняется только EPIC 2, остальное не страдает.
3. **Цель месяца:** ядро + онлайн 2-8 + хаб + столько мини-игр, сколько успеем (фундамент строится так, чтобы каждая следующая игра добавлялась дёшево). Реалистичный минимум для «готовой игры» — ядро + 4-6 мини-игр; остальные добиваются по той же схеме.
4. **Арт:** стор-ассеты + AI (Blender/Hyper3D для 3D, Higgsfield для промо). Не моделим с нуля.
5. **Приоритет мини-игр:** сначала простые «все против всех» без сложной сети (Секундомер, Порядок банок, Рейс на память), потом физические/асимметричные.
