# Проверка и закрытие

> **Модель: Sonnet 5.** Прогнать чеклист, прочитать консоль, подвинуть статусы. Если проверка вскрыла настоящий баг — переключиться на Opus 5 и чинить уже там.

Быстрый прогон перед тем, как что-то назвать готовым. Дешевле, чем ловить это на плейтесте.

## 1. Компиляция и консоль

```
mcp__unity__refresh_unity
mcp__unity__read_console (types: error, поверх — warning от нашего кода)
```

Ошибок быть не должно. Предупреждения из `Assets/_Project/` — тоже разобрать; предупреждения из пакетов игнорировать.

## 2. Ревью по правилам проекта

Пройти по изменённому коду и проверить против `igruha/CLAUDE.md`:

**Код:**
- [ ] Нет магических чисел — всё в константах, `[SerializeField]` или конфиге
- [ ] Компоненты кэшированы в `Awake`/`Start`, `GetComponent` не вызывается в `Update`
- [ ] Нет `FindObjectOfType`/`FindAnyObjectByType` в рантайме
- [ ] Нет аллокаций (`new`, LINQ, строки, boxing) в `Update`/`FixedUpdate`/`LateUpdate`
- [ ] Физика в `FixedUpdate`, ввод и визуал в `Update`
- [ ] `[SerializeField] private` вместо `public` для инспекторных полей
- [ ] Нет God-классов, логика не продублирована из Core
- [ ] Нет заглушек и TODO без явной просьбы

**Сеть (если код сетевой):**
- [ ] Состояние — в `NetworkVariable`, не в повторяющихся RPC
- [ ] Каждый `ServerRpc` валидирует входные данные, ничего не берёт от клиента на веру
- [ ] Исходы, рандом, очки и места считаются на сервере
- [ ] Проверки `IsServer`/`IsOwner` стоят там, где логика ролевая
- [ ] Спавн сетевых объектов — только на сервере
- [ ] Нет хардкода под число игроков

## 3. Поведение

Взять раздел «Как проверить» из тикета и пройти его. Если тикет из фазы «сеть» — обязательно два инстанса, не один.

## 4. Синхронизация статусов

- Тикеты в Linear: `In Review` → `Done` только после проверки поведения, иначе — обратно в работу с комментарием, чего не хватает.
- Обновить `STATE.md`: таблицы фаз, ближайшие шаги.
- Коммит с ID тикета, `git pull --rebase` перед пушем (работаем вдвоём в `main`).

## 5. Отчёт пользователю

Коротко, без воды:
- что изменено;
- что проверить в редакторе руками;
- что проверить по сети;
- что осталось незакрытым и почему.
