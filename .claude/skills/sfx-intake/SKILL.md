# Приёмка поставки звука

> **Sonnet 5 / medium.** Работа механическая: раскладка, импорт, сверка списков.
> Думать тут не о чем — всё сказано в паспорте поставки.

Вход: папка поставки (обычно `igruha/Komnata_*`), внутри — `sounds.json` и `SFX/**`.
Результат: клипы лежат в проекте, импортированы правильно, библиотеки собраны,
а пользователю названо, что из обещанного ещё не приехало.

## Что такое поставка

`sounds.json` — машиночитаемый паспорт: на каждый звук `id`, `files`,
`unity_target_folder`, `spatial` (2D/3D), `loop`, `unity_load_type`, лицензия.
Рядом лежит `INTEGRATION.md` — та же таблица словами, плюс раздел
**«Ещё не сделано»**. Читать нужно `sounds.json`; `INTEGRATION.md` — чтобы
понять замысел и забрать список недостающего.

Поставки приходят частями и перекрываются: `Komnata_SFX_CHR_batch3` и
`Komnata_SFX_UI_batch1` целиком вошли в более позднюю `Komnata_zvuk_2026-09-18`.
**Принимать надо самую свежую папку**, а старые проверить на совпадение и не
принимать повторно.

## Порядок

1. **Прочитать паспорт.** `sounds.json` — состав, `INTEGRATION.md` — раздел
   «Ещё не сделано».

2. **Пробный прогон.**
   ```
   python tools/sfx_intake.py <папка поставки> --dry-run
   ```
   Печатает, сколько слотов и файлов уедет в каждую папку. Сверить с ожиданием.

3. **Приёмка.**
   ```
   python tools/sfx_intake.py <папка поставки>
   ```
   Копирует файлы по `unity_target_folder` и дополняет манифесты
   `docs/art/<папка>-sfx.json`. Манифест опознаётся по `output_folder`, а не по
   имени файла — второй манифест на ту же папку затирал бы библиотеку первого.
   **Существующие слоты не трогаются**: перецелить старый слот на новый клип —
   решение прохода по игре, а не приёмки.

4. **Сборка библиотек** — в Unity меню `Igruha/Арт/Собрать все библиотеки звука`
   (или `SfxLibraryBuilder.BuildAll` рефлексией через мост). Печатает по каждой
   библиотеке: слотов, немых, клипов подхвачено.

   **Немой слот — это не ошибка, а заказ.** Манифест игры перечисляет всё, что
   ей нужно; приехавшее занимает свои слоты, остальные остаются пустыми. Список
   немых из лога — готовый перечень того, что просить у поставщика.

5. **Проверить импорт.** Настройки ставит автопостпроцессор `SfxClipImportSetup`
   сам, но только файлам с префиксом `SFX_`. Если поставка приехала до того, как
   постпроцессор появился, клипы надо переимпортировать:
   `AssetDatabase.ImportAsset(path, ImportAssetOptions.ForceUpdate)` по списку.

6. **Отчитаться пользователю** тремя списками: что приехало и встало, что из
   раздела «Ещё не сделано» ждём, что приехало, но пока никуда не привязано
   (клип в проекте есть, события в игре нет — это задача фазы 5 по игре).

## Правила формата — из паспорта, не выдумывать

| Правило | Почему |
|---|---|
| Force To Mono на 3D-звуках | стерео-клип Unity не спатиализует: шаг соседа звучит по центру головы |
| Streaming для лупов, Decompress On Load для коротких | луп в 30 с иначе разворачивается в память целиком; короткий иначе опаздывает на кадр |
| Вариации `_01.._NN` — случайная без повтора, высота ±5% | пять файлов по кругу слышны как пулемёт |
| Не больше 4 копий одного звука на арену | при восьми игроках девятый одинаковый удар слышен как каша |
| Громкость правится на `AudioSource`, файлы не перенормализовывать | клипы уже нормализованы по пику |

Первые четыре правила уже реализованы в коде (`SfxClipImportSetup`,
`MinigameAudioPlayer`) — проверять их руками на каждой поставке не нужно.

## Лицензии

Sonniss GDC Game Audio Bundle и Kenney: в игре — свободно и коммерчески,
указывать авторов не обязательно. **Нельзя** продавать файлы отдельно и
**обучать на них ИИ**. Если заводится раздел звука в титрах — список библиотек
лежит в README поставки.

## Чего не делать

- Не переименовывать файлы поставки. Следующая поставка приедет под теми же
  именами и разойдётся с проектом. Если игровой код зовёт слот своим именем —
  для этого в манифесте есть поле `file`.
- Не коммитить саму папку поставки. WAV идут через LFS, и копия рядом с
  `Assets/` удваивает вес репозитория. Папки поставок закрыты `.gitignore`.
- Не заводить звук мимо поставки. Генерация fal.ai выведена из процесса
  19.09.2026, а сгенерированное ею удалено: черновик, считавшийся готовым
  звуком, делал игру «озвученной», не будучи ею. Если звука нет — он в заказе,
  а не в проекте.
