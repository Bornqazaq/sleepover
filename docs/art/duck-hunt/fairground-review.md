Скрипт `DuckHuntBlockoutCheck` запускается вручную в локальном Play Mode. Для MPPM имеется явный EditorPrefs opt-in `Igruha.DuckHunt.NetworkQA` (по умолчанию false; после этой сессии выключен). По сети нужен повтор после чистого перезапуска Unity. Не включать автоматическую проверку в обычной игре.

Общий URP, ростер, контроллеры анимаций и параметры капсул не менялись. Геометрия окружения объединена по общим материалам; отдельный FPS/LOD-проход ещё не выполнен.
