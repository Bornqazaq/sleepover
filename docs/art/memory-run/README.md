Повторное уточнение 17.09.2026: прежний слишком открытый вариант ниже заменён
более цельным и тёмным зданием. Восстановлены большая часть кровли, верх боковых
стен и дальний угол. Оставлены два локальных рваных боковых проёма, отдельные

близких высоких цехов, резервуары, уличные фонари, краны и трубы.

собственная Flame-текстура, небольшое пламя, искры, дым и тёплый точечный свет.
Это постоянный фоновый декор, без урона и без связи с событиями игровых мин.

## Воспроизведение

1. Исходник: `igruha/Assets/_Project/Art/Source/MemoryFoundry/MemoryFoundryKit.blend`.
2. Экспорт: Blender в background с `--python tools/blender/memory_foundry.py` из корня проекта. Генератор использует собственные геометрические helpers из `crying_angels.py`, не магазинные модели.
3. Unity: `Igruha/Рейс на память/Построить арену`. Импорт оригинальных материалов включён в сборщик.
4. Аудит: `Igruha/Рейс на память/Замеры арта`, результат в [audit.txt](audit.txt).
5. Сетевой стенд: development macOS build с Boot, Hub, MemoryRun в `Builds/MemoryFoundry/sleepover.app`, затем `bash tools/memory-foundry-check.sh`.

Структура набора: 40 FBX, девять собственных текстур, палитра URP,
Blender-исходник, детерминированный генератор. Рекурсивный граф сцены не
содержит Synty/Polygon. Неиспользуемые старые паки оставлены для других игр.
