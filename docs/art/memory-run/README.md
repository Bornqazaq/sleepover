## 17.09 — пассивное тело после поражения (уточнение IGR-534)

Пользователь принял окружение и попросил заменить жёсткую позу при попадании
на соседнюю плиту. `MemoryRunRagdoll` создаёт только на время поражения 11
физических частей и 10 пассивных суставов по текущему humanoid-скелету.
Низкое трение и небольшой поверхностный сдвиг сохраняют скольжение после
плоского удара. В полёте нет удержания позы. Тело сталкивается с окружением,
но не толкает живых игроков. Возврат через 2.8 с полностью восстанавливает
