# CarryItem — стройка небоскрёба, IGR-535

Собственный Blender-набор заменяет Synty в сцене и всех четырёх игровых префабах.
38 FBX, исходник `igruha/Assets/_Project/Art/Source/CarrySkyscraper/CarrySkyscraper.blend`,
генератор `tools/blender/carry_skyscraper.py`. Текстуры бетона, древесины, сетки
и частиц тоже созданы в этом проходе.

## Воспроизведение

1. Запустить генератор через Blender MCP. Он меняет только свои сцены `CarrySkyscraper_*`.
2. В Unity открыть CarryItem в Edit Mode, вызвать `CarryItemArenaBuilder.Rebuild()`, сохранить сцену.
3. Вызвать `CarryItemArtAudit.Measure()`, `CarryItemTrafficAudit.Run(out report)`.
4. Вызвать `ArtBake.BakeActiveScene()` кодом. Для этой сцены ответ: Synty-зависимостей нет.
5. Собрать development macOS с Boot, Hub, CarryItem. Запустить
   `tools/carry-skyscraper-check.sh 4 4` или `tools/carry-skyscraper-check.sh 8 2`.
   Второй аргумент — сколько процессов рендерить, третий — ширина окна.

## Найдено и исправлено по прогонам

- Сохранён импортный поворот FBX внутри обёртки: прежнее присваивание yaw
  укладывало стояк на бок и увеличивало коллизию до 4.39 м.
- Тачки вынесены из подходов, стояк перемещён к выходу из горлышка.
- Настил расширен с 1.44 до 3.24 м: четыре несущих помещаются по ширине.
- Штабели вынесены в боковые рабочие зоны; заднее место несущего больше
  не пересекается со штабелем.

Первый смешанный сетевой прогон также выявил клиентское падение без возврата.
Это наблюдение сохранено: `network-4-20260917-172928/client-3-probe.txt`.
После расширения настила полный прогон четырёх отображаемых клиентов
`network-4-20260917-173447` завершился 100:59, все четыре вернулись в хаб,
ошибок и проваливаний не было. Это промежуточный прогон до переноса штабелей.
Итоговый прогон `network-4-20260917-175854`: 198:100, доставки 2/1,
200 с, четыре участника; все получили одинаковый результат и вернулись в Hub.
Минимальная Y: −0.03 м, runtime-исключений нет.
[Сводка четырёх игроков](network-4-summary.json).
После этого прогона уточнены только небесное заполнение/skybox и стойки
флажков за штабелями; финальные ArtAudit и повторная пересборка пройдены.
Console при съёмке: 0 ошибок, два предупреждения Metal/ScreenCapture
о memoryless depth; при сборке — предупреждение Addressables
`ProfileValueReference: GetValue called with empty id`. Финальный Build
`build-72680e1e83`: Succeeded, 953.4 MB, 0 errors / 0 warnings.
Восемь одновременно отображаемых клиентов дали около 8 FPS на этой машине:

### IGR-696 — эстакада и захват тележки

Сохранены бетонный недострой и золотой час; новый акцент — тёмная стальная эстакада с охристыми краями над дорогой. Верхний путь даёт длинный подъём и крановую опасность, нижние пути — выбор короткого настила или широкого обхода. Полотно эстакады имеет единый замкнутый коллайдер без внутренних торцов секций; концы рамп отнесены от края этажа, оставляя ровные площадки по 5.36 м для торможения и разворота. Добавлены боковые переправы, ступени для перехвата, катушки и генераторы в рабочих группах. Из габаритов новых путей убраны прежние леса, ограждения, бытовка и тачка. Насосы теперь в цветных карманах на своих сторонах, вне сквозного движения.

Свой набор: Deck, SideDeck, Rail, Trestle, Crane, SuspendedBeam, CableReel, Generator, PumpSign. Повторно используются материалы Roadworks. Генератор `tools/blender/carry_heist_routes.py`, исходник `Art/Source/CarrySkyscraper/CarryHeistRoutes.blend`. Новый `CarryHeistArena` автоматически входит в `CarryRoadArena.Apply()` и полную пересборку арены. Замороженные персонажи, общая камера и клипы не менялись.

Кража показана перекраской тележки в текущую команду; HUD ввода сопровождает действительно удерживаемую тележку. Шланг подключается к той таре, которую принял насос. Новых звуков / голосов нет.


Проверка слоя: 971 положений тележки с четырьмя капсулами на дорогах, рампах, мостах и в заездах — без пересечения препятствий или выхода станций над пустотой. Повтор применения нового слоя: 345 → 345 Transform. Новый слой: 176 Renderer / 101 572 треугольника; MeshRenderer всей сцены 1628 → 1778 (+9.2%). Это геометрическая оценка, не GPU-бенчмарк.
