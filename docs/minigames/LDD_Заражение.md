# «Заражение» — Level Design Document

**Проект:** Комната
**Версия:** 1.0
**Статус:** к реализации
**Категория:** все против всех, догонялки с нарастанием
**Схема арены:** см. файл `Схема_арены_Заражение.svg`

---

## 1. Краткое описание

Классические дворовые догонялки-«зараза» на детской площадке.

Раунд начинается с того, что все игроки — **Чистые**. Через несколько секунд один случайный игрок покрывается зелёной краской и становится **Нулевым пациентом**. Его касание заражает. Заражённый **тоже начинает заражать** — и к концу раунда за последним Чистым бежит толпа из семи человек.

Побеждает тот, кто продержался чистым дольше всех. Заражённым выгодно **продолжать ловить**: каждое личное заражение даёт бонус к месту.

**Ядро геймплея:** снежный ком. Первые секунды — лёгкая разминка, последние — тотальный хаос, когда убежать почти невозможно. Напряжение создаётся не сложностью арены, а нарастающим числом преследователей. Каждый объект площадки — это способ выиграть две секунды жизни.

---

## 2. Единицы измерения

Все размеры даны в **ШП — ширинах персонажа** (диаметр коллайдера персонажа).
Программист подставляет реальные значения при настройке контроллера.

Система координат схемы: начало в **юго-западном углу арены**, ось X на восток (0–48), ось Y на север (0–36).

---

## 3. Состав лобби и роли

| Параметр | Значение |
|---|---|
| Минимум игроков | 4 |
| Максимум игроков | 8 |
| Нулевых пациентов | 1 |
| Чистых на старте | все |

**Выбор Нулевого пациента:** случайный из тех, кто ещё не был Нулевым в этой катке. Если все были — сброс истории.

При лобби менее 4 человек мини-игра **исключается из пула**: при 1 заражающем и 1–2 убегающих механика снежного кома не работает.

## 4. Параметры раунда

| Параметр | Значение | Примечание |
|---|---|---|
| Длительность раунда | 60 сек | отсчёт очков идёт с момента появления Нулевого |
| Обратный отсчёт до старта | 3 сек | все стоят на точках спавна |
| Фаза разбегания | 3 сек | все бегают Чистыми, Нулевой ещё не назначен |
| Грейс Нулевого | 2 сек | заражён, мигает, но заражать не может |
| Условие досрочного конца | все игроки заражены | |

Фаза разбегания нужна, чтобы Нулевой не заражал соседей по спавну на первой секунде и чтобы никто не знал заранее, от кого бежать.

## 5. Геометрия арены

### 5.1 Общие размеры

| Элемент | Размер |
|---|---|
| Форма | прямоугольник со скруглёнными углами |
| Размеры | 48 × 36 ШП |
| Ограждение по периметру | забор высотой 3 ШП, непроходимый |
| Перепады высот | арена плоская; единственная вертикаль — горка |

### 5.2 Принципы расстановки

1. **Карусель в центре** — главная орбита. Большинство погонь крутится вокруг неё; вокруг платформы всегда можно бежать в обе стороны.
2. **Вокруг каждого объекта минимум два обхода.** Ни один объект не прижат к забору вплотную.
3. **Никаких тупиков.** По периметру идёт сплошная беговая дорожка шириной не менее 3 ШП.
4. **Проходы между объектами одинаковой ширины (3–4 ШП)** — чтобы толпа не собиралась в единственной узости.
5. **Объекты одного назначения разнесены**: обе «спасательные» точки (трубы и лазалка) стоят на противоположных краях арены.

### 5.3 Координаты объектов

| Объект | Положение (ШП) | Габарит |
|---|---|---|
| Карусель | центр (24, 18) | платформа Ø 8, высота 0.4 |
| Горка | (6.5–9.5, 22–30) | лестница с севера, скат на юг |
| Качели | (33–41, 26.5–29.5) | рама 8 ШП, 2 сиденья, качаются по оси север–юг |
| Трубы | (3.5–5.5, 11–17) и (7.5–9.5, 11–17) | две параллельные, Ø 2, длина 6 |
| Лазалка | (39–44, 11.5–16.5) | куб 5 × 5, два сквозных прохода |
| Песочница | (19.5–28.5, 3–9) | 9 × 6, борт 0.4 |

### 5.4 Спавн

8 точек по периметровой дорожке, максимально разнесённых:

(13, 3), (35, 3), (45, 10), (45, 26), (35, 33), (13, 33), (3, 26), (3, 10)

При неполном лобби игроки распределяются так, чтобы **максимально разнести их друг от друга** — как в «Плачущих ангелах».

## 6. Объекты площадки и их роль в механике

Каждый объект существует не для декора — у каждого есть функция в погоне.

### 6.1 Карусель (центр)

| Параметр | Значение |
|---|---|
| Платформа | Ø 8 ШП, вращается |
| Скорость вращения | 30°/сек (полный оборот за 12 сек) |
| Поведение игрока на платформе | движется вместе с платформой |

Функция: главный «остров» орбиты + элемент непредсказуемости. Забежал на платформу — тебя сносит, и сойдёшь не там, где рассчитывал преследователь.

> **Флаг реализации:** движущаяся платформа, несущая игроков — потенциально дорогая вещь в сетевом коде. Заложить два варианта: **А** — платформа вращается и несёт игроков; **Б** — вращается только визуальная надстройка (поручни), пол статичен. Решение за программистом после теста синхронизации. Геймплейно вариант Б теряет мало: орбита вокруг карусели работает в обоих.

### 6.2 Горка

Единственный односторонний путь и единственная вертикаль арены.

| Параметр | Значение |
|---|---|
| Подъём по лестнице | ~2 сек, скорость лазания фиксированная |
| Скат | ускоренный спуск ~1 сек, управление отключено |
| Точка приземления | фиксированная, на 2 ШП южнее конца ската |

Функция: рискованный манёвр. Оторвался от преследователя — но пока лез, толпа могла собраться у точки приземления. Подъём **нельзя прервать** — начал лезть, лезь до конца.

Заражённые пользуются горкой на общих основаниях.

### 6.3 Качели

| Параметр | Значение |
|---|---|
| Сидений | 2 |
| Амплитуда | качаются постоянно, рассинхронизированы между собой |
| Контакт с игроком | сбивает с ног: проигрывается клип падения ~1 сек, игрок не управляем |

Функция: элемент случайности на быстром маршруте. Бьют и Чистых, и Заражённых. Сбитый Чистый — лёгкая добыча; сбитый Заражённый — подарок убегающему.

Сбитие — **заготовленный клип**, без рэгдолла (проектный стандарт). Касание качелей заражение **не передаёт** — только прямое касание игрока игроком.

### 6.4 Трубы

Две параллельные трубы Ø 2 ШП. Игрок пробегает насквозь без приседания.

Функция: обрыв прямой видимости. Заражённый не знает, из какого конца и из какой трубы ты выйдешь. Две трубы рядом дают «напёрстки»: вбежал в одну — вышел из соседней.

**Читаемость:** когда внутри трубы находится игрок, её стенки для остальных становятся полупрозрачными — силуэт виден, но с задержкой чтения. Никто не должен врезаться в невидимое (проектный стандарт).

### 6.5 Лазалка

Куб 5 × 5 ШП из перекладин с **двумя сквозными проходами** крест-накрест. По верху лазать нельзя — только пробегать насквозь.

Функция: узкое место. Толпа преследователей в проходах создаёт пробку, один проскальзывает. Зеркальный ответ трубам на противоположном краю арены.

### 6.6 Песочница

| Параметр | Значение |
|---|---|
| Замедление | ×0.7 к скорости для всех |
| Борт | 0.4 ШП, перешагивается автоматически |

Функция: тактический выбор. Срезать через песок быстрее по расстоянию, но медленнее по скорости — и заражённый, вошедший следом, замедляется так же. Осознанная ставка, а не ловушка.

## 7. Механика заражения

### 7.1 Состояния игрока

```
ЧИСТЫЙ ──касание Заражённого──> ЗАРАЖАЕТСЯ (0.7 сек) ──> ЗАРАЖЁН (до конца раунда)

НУЛЕВОЙ ПАЦИЕНТ: назначение ──> ГРЕЙС (2 сек, не заражает) ──> ЗАРАЖЁН
```

### 7.2 ЧИСТЫЙ

Обычное управление. Скорость 1.0×.

### 7.3 ЗАРАЖАЕТСЯ (переходное, 0.7 сек)

- Проигрывается клип заражения: всплеск зелёной краски, персонаж отряхивается
- Игрок не управляем
- **Не заражает и не может быть «перезаражён»** — неуязвим для всех проверок
- Нужен, чтобы в толпе не срабатывали цепочки заражений за один кадр

### 7.4 ЗАРАЖЁН

- Скорость **0.95×** — Чистый всегда чуть быстрее, убежать реально даже по простой арене
- Касание Чистого передаёт заражение
- Кулдаун после собственного заражения: **1.0 сек** — свежезаражённый не пятнает бывшего преследователя мгновенно
- Обратного пути нет, лечения нет

### 7.5 Касание

| Параметр | Значение |
|---|---|
| Радиус касания | 1.2 ШП между центрами капсул |
| Проверка | по пересечению коллайдеров, серверная |
| Два Заражённых коснулись одного Чистого в один кадр | заражение засчитывается тому, кто раньше по серверному времени; при равенстве — случайно |

### 7.6 Визуал состояний

| Состояние | Вид |
|---|---|
| Чистый | обычный скин персонажа |
| Заражённый | персонаж **измазан зелёной краской**: пятна на одежде, руках, лице + зелёные капли-следы при беге |
| Нулевой в грейсе | то же + мигание, чтобы все успели среагировать |

Краска понятнее абстрактного свечения и вписывается в детскую тему. Заражённый должен опознаваться **силуэтом и цветом с любого расстояния** — это главный элемент читаемости всей мини-игры.

---

## 8. Камеры и управление

Стандартная камера проекта от третьего лица, как в остальных мини-играх. Особых режимов нет.

Спектаторов нет — заражённые продолжают играть до конца раунда, у них своя мотивация (см. очки).

---

## 9. Звук

| Событие | Слышит | Радиус |
|---|---|---|
| Шаги Заражённого | все | обычная громкость + влажные «шлёпающие» шаги |
| Всплеск заражения | все | яркий сочный «сплэт» |
| Назначение Нулевого | все | короткий тревожный акцент |
| Скрип карусели | все | постоянный, от центра, 12 ШП |
| Скрип качелей | все | ритмичный, 8 ШП |
| Сердцебиение | Чистый | включается, когда Заражённый ближе 5 ШП |

Шлёпающие шаги заражённых — звуковое предупреждение со спины: Чистый должен иметь шанс среагировать на то, чего не видит.

## 10. Диктор

Тональность — комментатор дворовых страстей. Примеры реплик по событиям:

| Событие | Пример |
|---|---|
| Назначение Нулевого | «Кажется, у [имя] что-то зелёное на руках. Я бы отошёл.» |
| Первое заражение | «Один готов. Дальше — математика.» |
| Заражена половина | «Напоминаю: это была дружеская игра.» |
| Остался один Чистый | «Семеро против одного. Честно как никогда.» |
| Игрок сбит качелями | «Качели сегодня без команды, но с результатом.» |
| Досрочный конец | «Все зелёные. Расходимся, домой зовут.» |

## 11. Подсчёт очков

### 11.1 Формула

Место определяется **очками времени**:

> **Очки = секунды, прожитые Чистым + 6 сек за каждое личное заражение**

Нулевой пациент дополнительно получает **компенсацию +10 сек** (он не имеет чистого времени в принципе).

### 11.2 Что это даёт

- Выжившие Чистые почти всегда выше заражённых — выживание остаётся главной целью
- Заражённому **выгодно ловить**, а не стоять в углу: каждый пойманный — +6 сек к месту
- Нулевой не обречён на последнее место: активный Нулевой с 4–5 личными заражениями обгоняет тех, кто заразился в середине раунда и сдался

### 11.3 Пример при 8 игроках

| Игрок | Чистое время | Личных заражений | Компенсация | Очки | Место |
|---|---|---|---|---|---|
| A (выжил) | 60 | — | — | 60 | 1 |
| B (выжил) | 60 | — | — | 60 | 1 |
| C | 48 | 1 | — | 54 | 3 |
| D (Нулевой) | 0 | 6 | 10 | 46 | 4 |
| E | 35 | 1 | — | 41 | 5 |
| F | 30 | 0 | — | 30 | 6 |
| G | 22 | 1 | — | 28 | 7 |
| H | 15 | 0 | — | 15 | 8 |

Выжившие с равными очками делят место. Прочие ничьи — по серверному времени последнего события, при полном равенстве случайно.

## 12. Крайние случаи

| Ситуация | Поведение |
|---|---|
| Нулевой отключился до первого заражения | Нулевым назначается случайный Чистый, его грейс 2 сек, таймер раунда не сбрасывается |
| Нулевой отключился после первого заражения | Ничего — заражённых уже больше одного |
| Чистый отключился | Считается заражённым на момент отключения, без чьего-либо бонуса |
| Заражённый отключился | Его очки фиксируются как есть |
| Все заражены до таймера | Раунд заканчивается досрочно |
| Игрок в состоянии ЗАРАЖАЕТСЯ в момент финального свистка | Считается заражённым |
| Игрок застрял в геометрии | Автотелепорт на ближайшую точку спавна через 3 сек |
| Игрок застрял на карусели / в трубе | Тот же автотелепорт |

## 13. Чеклист реализации

**Арена**
- [ ] Прямоугольная площадка 48 × 36 ШП с забором
- [ ] Периметровая дорожка ≥ 3 ШП без тупиков
- [ ] Расстановка шести объектов по координатам из 5.3
- [ ] 8 точек спавна
- [ ] Проверка: вокруг каждого объекта два обхода, проходы 3–4 ШП

**Объекты**
- [ ] Карусель: вариант А (несущая платформа) или Б (статичный пол) — по итогам теста синхронизации
- [ ] Горка: непрерываемый подъём, скат без управления, фиксированное приземление
- [ ] Качели: постоянное качание, сбивание клипом ~1 сек, без передачи заражения
- [ ] Трубы: сквозной проход, полупрозрачность стенок при игроке внутри
- [ ] Лазалка: два сквозных прохода, верх непроходим
- [ ] Песочница: зона ×0.7 к скорости

**Механика заражения**
- [ ] Машина состояний ЧИСТЫЙ / ЗАРАЖАЕТСЯ / ЗАРАЖЁН
- [ ] Назначение Нулевого после фазы разбегания, грейс 2 сек с миганием
- [ ] Серверная проверка касания, радиус 1.2 ШП
- [ ] Кулдаун 1.0 сек после собственного заражения
- [ ] Разность скоростей 1.0× / 0.95×
- [ ] Клип заражения 0.7 сек с неуязвимостью
- [ ] Визуал краски: пятна + следы при беге

**Логика раунда**
- [ ] Отсчёт 3 сек → разбегание 3 сек → назначение Нулевого → таймер 60 сек
- [ ] Досрочное завершение при полном заражении
- [ ] Подсчёт очков: чистое время + 6 сек/заражение + компенсация Нулевого
- [ ] Обработка дисконнектов по разделу 12

**Звук и диктор**
- [ ] Шлёпающие шаги заражённых
- [ ] Сплэт заражения, акцент назначения Нулевого
- [ ] Сердцебиение при Заражённом ближе 5 ШП
- [ ] Реплики диктора по событиям из раздела 10

**Флаги для плейтеста**
- [ ] Все параметры из раздела 14 вынесены в инспектор

## 14. Параметры для подбора на плейтесте

Всё в этой таблице **обязательно должно настраиваться без пересборки**.

| Параметр | Стартовое значение | Приоритет |
|---|---|---|
| Множитель скорости Заражённого | 0.95× | **критический** |
| Бонус за личное заражение | 6 сек | **критический** |
| Компенсация Нулевого | 10 сек | высокий |
| Длительность раунда | 60 сек | высокий |
| Радиус касания | 1.2 ШП | средний |
| Замедление песочницы | ×0.7 | средний |
| Скорость вращения карусели | 30°/сек | средний |
| Грейс Нулевого | 2 сек | средний |
| Кулдаун свежезаражённого | 1.0 сек | низкий |
| Фаза разбегания | 3 сек | низкий |

**Порядок настройки:** сначала множитель скорости — он определяет, играбельна игра вообще (0.9× — заражённые беспомощны, 1.0× — Чистые обречены). Потом бонус за заражение — он определяет, продолжают ли заражённые играть. Всё остальное после.

**Ожидаемая проблема:** при 8 игроках финал раунда может превращаться в безнадёжную стенку из 7 преследователей. Если так — проверить увеличение арены на 10–15% для полного лобби, прежде чем трогать скорости.

## 15. Арт-дирекшн

**Локация:** детская игровая площадка, тёплый летний вечер.

| Элемент | Описание |
|---|---|
| Покрытие | мягкая резиновая плитка двух цветов, крупные округлые зоны |
| Забор | низкий деревянный, скруглённый штакетник ярких цветов |
| Карусель | круглая платформа с гнутыми поручнями, выцветшие сектора красного и жёлтого |
| Горка | пластиковая, пузатая, ярко-жёлтый скат, красная лестница |
| Качели | А-образная рама, резиновые сиденья на цепях |
| Трубы | крупные пластиковые тоннели, тёплый оранжевый |
| Лазалка | куб из скруглённых перекладин, разноцветный |
| Песочница | деревянный борт, тёплый песок, забытые формочки и совок |
| Фон за забором | дворовые пятиэтажки в дымке, деревья, тёплый гаснущий свет окон |
| Свет | закатное солнце + один включившийся фонарь; настроение «скоро домой позовут» |

**Стиль:** единый со всем проектом — гладкий матовый пластик, округлые упрощённые формы, насыщенные цвета, без обводки, без текстурного шума. Площадка должна выглядеть как крупная игрушка.

**Ключевое требование по читаемости:** зелёный цвет заражения не должен встречаться в палитре арены. Ни один объект площадки не красить в зелёный — заражённый обязан читаться мгновенно на любом фоне.

**Силуэты:** все шесть объектов узнаются силуэтом с любого ракурса и с высоты камеры. Игрок с первой секунды понимает, что горка — это горка, без обучения.
