# «Плачущие ангелы» — Level Design Document

**Проект:** Комната
**Версия:** 1.0
**Статус:** к реализации
**Категория:** асимметричная мини-игра (1 против всех)

---

## 1. Краткое описание

Один игрок — **Водящий** — стоит в центре круглой арены с фонарём и вращается вокруг своей оси. Остальные — **Бегущие** — стартуют по краю арены и пробираются к центру, прячась за статуями.

Тот, на кого попал луч фонаря, **не может двигаться**. Если Водящий удерживает луч на игроке 4 секунды подряд — игрок **окаменевает** и возвращается на старт.

Цель Бегущего — **дотронуться до Водящего**. Цель Водящего — **не пропустить никого** до конца таймера.

**Ядро геймплея:** Водящий физически не может смотреть во все стороны. Пока он добивает одного, остальные идут свободно. Каждую секунду он выбирает, кем пожертвовать.

---

## 2. Единицы измерения

Все размеры даны в **ШП — ширинах персонажа** (диаметр коллайдера персонажа).
Программист подставляет реальные значения при настройке контроллера.

Пример: если ШП = 0.6 юнита, то диаметр арены 40 ШП = 24 юнита.

## 3. Состав лобби и роли

| Параметр | Значение |
|---|---|
| Минимум игроков | 3 |
| Максимум игроков | 8 |
| Водящих | 1 |
| Бегущих | все остальные |

**Выбор Водящего:** случайный из тех, кто ещё не был Водящим в этой катке. Если все были — сброс истории.

При лобби менее 3 человек мини-игра **исключается из пула**.

## 5. Геометрия арены

### 5.1 Общие размеры

| Элемент | Размер |
|---|---|
| Диаметр арены | 40 ШП |
| Радиус арены | 20 ШП |
| Высота стен по периметру | 6 ШП (непроходимые) |
| Форма | правильный круг |

### 5.2 Зоны (от центра наружу)

| Зона | Радиус | Содержимое |
|---|---|---|
| Постамент Водящего | 0–3 ШП | Круглая платформа, высота 0.5 ШП |
| Голая зона | 3–8 ШП | **Укрытий нет вообще** |
| Внутреннее кольцо | 8–13 ШП | Редкие укрытия, ~6 шт |
| Среднее кольцо | 13–16 ШП | Средняя плотность, ~10 шт |
| Внешнее кольцо | 16–19 ШП | Плотно, ~16 шт |
| Спавн | 19 ШП | 8 точек равномерно по окружности |

**Принцип:** плотность укрытий падает к центру. Последний рывок всегда делается по открытому месту. Это пик напряжения каждой попытки.

### 5.3 Постамент

Водящий стоит на платформе высотой 0.5 ШП. Она даёт ему обзор поверх низких укрытий.

Водящий **не может сойти с постамента**. Он только вращается.

### 5.4 Спавн

8 точек равномерно по окружности радиусом 19 ШП, с шагом 45°.

При старте раунда игроки распределяются по точкам так, чтобы **максимально разнести их друг от друга**. При 4 игроках — через одну точку, и т.д.

Это гарантирует, что Водящий не сможет держать всех в одном конусе.

## 6. Укрытия

### 6.1 Два типа

| Тип | Высота | Поведение |
|---|---|---|
| **Низкое** | 1.2 ШП | Полностью блокирует луч, если игрок присел. Стоя — видно голову |
| **Высокое** | 2.5 ШП | Блокирует луч всегда |

Соотношение примерно 60% низких, 40% высоких.

### 6.2 Визуал

Все укрытия — **каменные статуи на низких постаментах**. Разные позы, разный размер.

**Важная механика блефа:** окаменевший игрок визуально становится такой же статуей. Водящий не всегда понимает, какая фигура была тут изначально, а какая — застывший игрок.

### 6.3 Расстановка

Расставлять **вручную, не процедурно**. Требования:

- Между укрытиями должны быть проходы шириной не менее 2 ШП
- Не должно быть «коридоров», позволяющих дойти до центра, ни разу не выйдя на открытое место
- Не должно быть мёртвых зон, куда луч физически не достаёт
- Ни одно укрытие не должно полностью перекрывать сектор обзора Водящего

### 6.4 Опциональная механика (обсуждается)

Окаменевший игрок **оставляет свою статую на арене** до конца раунда, и она работает как новое укрытие.

Плюс: арена меняется по ходу раунда, тематически идеально.
Риск: к концу раунда укрытий становится слишком много, Водящий слабеет.

**Решение принять на плейтесте.** Заложить как флаг, включаемый в настройках.

---

## 7. Фонарь

| Параметр | Значение |
|---|---|
| Угол конуса | 35° |
| Дальность | 20 ШП (весь радиус арены) |
| Изменение угла игроком | нет, фиксированный |
| Включение/выключение | нет, горит всегда |

**Проверка попадания:** игрок считается освещённым, если находится внутри конуса **и** между ним и Водящим нет препятствия (raycast).

Проверка идёт по **центру капсулы игрока**, а не по краю — иначе будет дёргаться на границе конуса.

Частота проверки: каждый кадр (или каждый физический тик).

## 8. Состояния Бегущего

```
СВОБОДЕН ──луч попал──> ЗАМОРОЖЕН ──таймер 4 сек──> ОКАМЕНЕЛ
    ^                        │                           │
    └────луч ушёл────────────┘                           │
    ^                                                    │
    └──────────респавн на своей точке────────────────────┘
```

### 8.1 СВОБОДЕН

Обычное управление. Может бежать, приседать, прыгать.

### 8.2 ЗАМОРОЖЕН

- Ввод движения полностью заблокирован
- Персонаж мгновенно принимает **случайную нелепую позу** из набора (6 вариантов)
- Камера **остаётся управляемой** — игрок может осматриваться, это важно для комфорта
- Переход обратно в СВОБОДЕН — **мгновенно**, как только луч ушёл

### 8.3 Таймер окаменения

| Параметр | Значение |
|---|---|
| Порог окаменения | 4.0 сек |
| Скорость накопления | 1.0× (пока луч на игроке) |
| Скорость отката | 0.5× (когда луча нет) |
| Полный откат с максимума | 8 сек |

**Важно:** откат идёт, пока игрок **свободно бегает**. Заморозка снимается сразу с уходом луча, таймер откатывается отдельно и не мешает движению.

Это даёт тактику: Водящий может давить на одну цель короткими подходами, накапливая её счётчик, вместо того чтобы держать 4 секунды подряд.

### 8.4 ОКАМЕНЕЛ

- Анимация окаменения (~0.5 сек)
- Респавн на **своей стартовой точке**
- Таймер окаменения сбрасывается в 0
- Никакого штрафа по очкам, только потеря позиции и времени

### 8.5 UI-индикация

Игрок должен видеть свой таймер окаменения. Предложение: **шкала, растущая по краям экрана** — чем ближе к окаменению, тем сильнее экран «каменеет» по периметру. Без цифр.

## 9. Касание Водящего

| Параметр | Значение |
|---|---|
| Радиус касания | 1.5 ШП от центра Водящего |
| Условие | Бегущий в состоянии СВОБОДЕН |
| Результат | Бегущий фиксирует своё место и **уходит в спектаторы** |

Замороженный игрок, стоящий вплотную, **не засчитывает касание**. Нужно быть свободным.

Раунд продолжается, остальные борются за следующие места.

---

## 10. Камеры и управление

### 10.1 Водящий — от первого лица

| Параметр | Значение |
|---|---|
| Камера | от первого лица |
| Управление | поворот мышью / стиком |
| Перемещение | **отсутствует**, только вращение |
| Максимальная скорость поворота | 90°/сек (полный оборот за 4 сек) |
| Вертикальный обзор | ограничен ±20°, чтобы не смотрел в пол и в потолок |

**Потолок скорости поворота — главный рычаг баланса всей мини-игры.** Обязательно вынести в настройки для подбора на плейтесте.

Ограничение скорости также снижает риск укачивания. Добавить настройку FOV в опциях.

### 10.2 Бегущие — от третьего лица

Стандартная камера проекта, как в остальных мини-играх.

### 10.3 Спектаторы

Свободная камера с возможностью переключаться между живыми игроками.

---

## 11. Звук

| Событие | Слышит | Радиус |
|---|---|---|
| Шаги Бегущего | Водящий | 6 ШП, тихо |
| Шаги Бегущего | другие Бегущие | обычная громкость |
| Момент заморозки | все | резкий короткий звук |
| Окаменение | все | звук трескающегося камня |
| Касание Водящего | все | яркий победный акцент |

Шаги для Водящего — намеренно тихие и неточные по направлению. Он должен **подозревать**, а не знать.

Приседание и медленная ходьба не издают шагов.

---

## 12. Подсчёт очков

### 12.1 Бегущие

Место определяется **порядком касания** Водящего.

Не дошедшие до конца таймера делят последние места **по расстоянию до центра** на момент финального свистка (ближе — выше).

### 12.2 Водящий

Та же формула, что в Duck Hunt:

> Водящий встаёт **выше всех, кого он не пропустил**, и **ниже всех, кто до него дошёл**.

Примеры при 8 игроках (1 Водящий + 7 Бегущих):

| Дошло Бегущих | Место Водящего |
|---|---|
| 0 | 1-е |
| 3 | 4-е |
| 7 | 8-е (последнее) |

---

## 13. Крайние случаи

| Ситуация | Поведение |
|---|---|
| Водящий отключился | Раунд завершается досрочно, всем Бегущим засчитывается прохождение |
| Все Бегущие отключились | Раунд завершается, Водящему 1-е место |
| Бегущий отключился в процессе | Его статуя/тело убирается, место не засчитывается |
| Игрок окаменел в момент финального свистка | Считается не дошедшим, расстояние берётся от точки окаменения |
| Два игрока коснулись Водящего в один кадр | Приоритет по серверному времени; при полном равенстве — случайно |
| Игрок застрял в геометрии | Автотелепорт на ближайшую точку спавна через 3 сек |

|---|---|---|
| Скорость поворота Водящего | 90°/сек | **критический** |
| Порог окаменения | 4.0 сек | **критический** |

## 16. Арт-дирекшн

**Локация:** заброшенный музей скульптуры ночью.

| Элемент | Описание |
|---|---|
| Пол | Растрескавшийся мрамор |
| Стены | Высокие, с арочными окнами под потолком |
| Свет | Холодный синий лунный из окон + луч фонаря как единственный тёплый источник |
| Атмосфера | Туман по полу, паутина, пыль в воздухе |
| Укрытия | Бледные каменные статуи на низких постаментах, часть с отбитыми лицами и вытянутыми руками |

**Ключевое требование по свету:** жёсткий контраст между лучом и темнотой. Страшно должно быть от контраста, а не от общей мутности. Луч даёт резкие длинные тени от статуй.

**Читаемость:** несмотря на темноту, силуэты статуй должны угадываться в тени за счёт холодной подсветки по контуру. Игрок не должен врезаться в невидимое.

## 17. Открытые вопросы

1. Остаются ли статуи окаменевших на арене (раздел 6.4) — решить на плейтесте
2. Нужна ли Водящему обратная связь о том, что его таймер на цели накапливается — предложение: луч слегка меняет цвет при удержании
3. Поведение при 3 игроках: Водящий против двоих может оказаться слишком сильным, проверить отдельно
