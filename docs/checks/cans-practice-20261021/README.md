# Счётчик совпадений в тренировке «Банок» — 21.10.2026

IGR-110, `fix/cans-all-solvers-ghosts`.

В тренировке добавлена отдельная карточка «На месте: N / 5». Она обновляется при изменении расстановки, а при полном совпадении предлагает Enter. Обычный цирковой HUD по-прежнему уступает место обучению; карточка живёт в собственном Canvas, не наследуя размеры старой нижней панели.

Сервер проверяет фазу тренировки, окно расстановки, номер хода, отправителя, состояние участника и корректность перестановки. Ответ содержит только число совпадений и возвращается одному автору запроса. Клиент сверяет ответ с текущими ходом и расстановкой. Повторный запрос отправляется только при изменении полки/хода, не каждый кадр. Проверка не подтверждает попытку и не меняет результат игрока. В настоящем раунде сервер не отвечает на такие запросы, карточка скрыта.

- `network.txt`: Host + 2 Clients с задержкой 75±20 мс в каждую сторону, все три PASS. Начальные частные ответы 3/5, 1/5 и 0/5; быстрая смена полки, отбрасывание устаревшего ответа, полный результат 5/5 без подтверждения и без попытки. После готовности всех — новая сцена настоящего раунда, запрос проверки запрещён, карточка отсутствует.
- `client-feedback.png`: фактический кадр сетевого клиента; карточка видна и читается рядом с обучением. Проверены также кадр хоста и переход в основной раунд.
- `build.json`: macOS Development Succeeded, 0 ошибок, 2 предупреждения. Оба предупреждения — разрыв WebSocket инструмента Unity MCP во время сборки (`build-warnings.json`), сборка завершилась нормально. Из игрового кода предупреждений нет.
