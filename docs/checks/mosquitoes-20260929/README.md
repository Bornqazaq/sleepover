Команда: `tools/autorun-mosquitoes.ps1 -Players 3 -Scenario entry-timeout -Giant 1 -Port 17829 -BuildDirectory igruha/Builds/Autotest/IGR-Network`.

- Игрок 0 вошёл в окно с остатком 8.68 с; игрок 2 по сценарию остался снаружи.
- Сервер убил игрока 2 с `deadline=10`. Все три участника получили эффект с `victim=2`.
- Итоги совпали у хоста и обоих клиентов: `0:1 1:3 2:1`. После завершения восстановлены три аватара, сетевых тел комаров нет.

- Сценарий завершает раунд коротким таймером после проверки входа/смерти; это не полный 120-секундный плейтест.
